# BUILDERS frontend

A mobile-first React + TypeScript frontend for BUILDERS.

## Run locally
1. Install Node.js 20+.
2. `npm install`
3. Copy `.env.example` to `.env`
4. Add your Supabase Project URL and publishable key.
5. `npm run dev`

The frontend is separate from the Supabase SQL/backend. Demo content keeps the UI populated while backend tables are being wired.
